UNDERSTANDING THE PROBLEM

What is Network Congestion?

Learn why networks slow down and how Dijkstra's algorithm helps optimize routing

What is Network Congestion?

Network congestion occurs when more data is sent through a network link than it can handle. Like a traffic jam on a highway, too many data packets cause delays, increased latency, and packet loss.

Key signs: Slow loading, buffering videos, dropped connections

Why Campus Networks Face This Issue

Campus networks serve thousands of users simultaneously. Students streaming videos, attending online classes, and downloading files create traffic spikes that overwhelm network links and routers.

Peak times: Morning classes, evening entertainment, exam periods

How Dijkstra Algorithm Solves This

Dijkstra's algorithm finds the shortest path between network nodes. When congestion is detected on a primary path, the system calculates alternate optimal routes to reroute traffic efficiently.

Benefit: Dynamic path optimization reduces congestion impact

ALGORITHM PROCESS

How Dijkstra Algorithm Optimizes Routing

Step-by-step explanation of network path optimization using Dijkstra's shortest path algorithm

1

Monitor Network Parameters

Network sensors continuously measure bandwidth usage, network delay, and packet loss on each link between routers.

2

Calculate Link Weights

Each network link is assigned a weight based on congestion level. Higher bandwidth usage and delay result in higher weights.

3

Detect Congestion

When any parameter exceeds threshold (Bandwidth >80%, Delay >60ms, Packet Loss >5%), the link is marked as congested.

4

Run Dijkstra Algorithm

The algorithm calculates the shortest path from source to destination, avoiding congested links by considering their higher weights.

5

Reroute Traffic

Traffic is automatically rerouted through the optimal alternate path, bypassing congested links and reducing network load.

CONCLUSION

Why Dijkstra Algorithm Matters

Key benefits of using shortest path algorithm for network optimization

Key Takeaways

1

Dynamic Path Selection

Unlike static routing, Dijkstra's algorithm dynamically calculates optimal paths based on current network conditions.

2

Weighted Decision Making

Link weights based on bandwidth, delay, and packet loss enable intelligent routing decisions that prioritize network health.

3

Guaranteed Optimal Solution

Dijkstra's algorithm guarantees finding the shortest path, ensuring traffic always takes the most efficient route.

4

Scalable Solution

The algorithm scales well with network growth, making it suitable for expanding campus and enterprise networks.

Algorithm Benefits

Reduced Latency

By always selecting the shortest weighted path, traffic experiences minimal delay even during congestion.

Load Balancing

Traffic naturally distributes across multiple paths as link weights adjust based on congestion levels.

Fault Tolerance

When links fail or become congested, the algorithm automatically finds alternate optimal paths.

This project demonstrates that Dijkstra's algorithm effectively optimizes network routing during congestion. By calculating link weights from bandwidth, delay, and packet loss, the system ensures traffic follows the most efficient path, reducing congestion impact on users.
